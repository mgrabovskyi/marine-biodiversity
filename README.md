# Marine Biodiversity: Protecting the Balance of Our Blue Planet

A student website for a PYP final project about marine biodiversity.

## Pages

- `index.html` — Home / central idea
- `line-of-inquiry-1.html` — Diversity of marine species
- `line-of-inquiry-2.html` — Interactions between marine organisms
- `line-of-inquiry-3.html` — Human impact and conservation
- `petxinot.html` — The Iberian Petxinot (endangered species)
- `help.html` — How we can help marine biodiversity

## How to view it

Open `index.html` in any web browser — no build step or server needed.
